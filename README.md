# Tires & Tread

Tires & Tread helps drivers understand tire fit, compare suitable options, estimate installed costs, and prepare for a conversation with an installer.

This repository currently contains the final design and implementation planning package, dated **October 22, 2026**. Phase 1 database, repository and headless service implementation is underway; the usable product has not been released. Product behavior and engineering decisions are specified; vendor contracts, tire-data rights, jurisdiction-specific policies, and production launch approvals remain explicit release gates.
