# Bundled report fonts

Noto Sans Regular and Bold are vendored under the accompanying SIL Open Font License 1.1. Upstream: [Noto fonts](https://github.com/notofonts/noto-fonts), `hinted/ttf/NotoSans/NotoSans-Regular.ttf` and `NotoSans-Bold.ttf`; license from the same repository's `LICENSE`. Retrieved 2026-11-03. These are static TrueType fonts, embedded from caller-supplied bytes with no runtime font fetch. Attribution and license travel with the assets.

Reviewed locale is en-US. The local specimens include Latin accents and expanded labels; this is not evidence of support for every Unicode writing system. Other locales and actual assistive-technology acceptance require separate review.
