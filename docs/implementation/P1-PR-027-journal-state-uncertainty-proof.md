The model admits eight **reduced synthetic event families**: operation, coordination, intent, dispatch observation, outcome, inventory observation, reconciliation and receipt marker. The derived receipt exposes planned-step effects and per-attempt history/status, current checkpoint and all false admission/trust flags. A receipt marker can yield `technical_evidence_only` only after all modeled steps succeed and the modeled holder is quiescent; later accepted changes invalidate the marker. An unavailable journal view stays quarantined. Receipts are not appendable records or bearer authority.

Envelopes bind fixed synthetic operation/project/domain/source/tree/image/config/manifest/release/credential-generation/review references, an allowed app/CMS/roles resource list and ordered steps. These digests are **sample labels**, not computed production image/config/catalog attestations. The fixed model project label is not the runner's random Docker project or an admitted database identity. `owned`, `absent`, quiescence and review are supplied **synthetic observations**, not actual creation provenance, administrator authority, process termination or provider capabilities. This narrower schema does not implement the full proposed target/resource/SQL/provider/custody envelope.

The codec pins **MODEL-ASCII-JSON-v1**: exact allowlisted shapes, ASCII enum/hex references, bounded integers, sorted object keys, compact JSON, preserved array order. It is not a general JSON canonicalization standard or production signer contract. Fatal invalid UTF-8/BOM, duplicate keys/alternate spellings, unknown fields, invalid outcomes and over-limit inputs refuse with a fixed diagnostic that does not echo raw input. Event size ≤64 KiB, planned steps ≤256, resources ≤64 (the allowed unique set is narrower), synthetic epochs ≤1,000,000 and history ≤4,096 events. Valid opaque hex cannot establish whether a caller derived it from secret material; callers here use fixed synthetic values only. No secret, URI, SQL/error body or private data field is accepted.

Each event has exact operation/domain/epoch, sequence, previous/content digest and data. Expected-head comparison, semantic reduction and event/index commit happen in **one synchronous in-memory instance**: clone and validate before replacing state. A stale competing expected head refuses; a byte-identical existing event under the current head is recognized without appending or causing effects. Domain-wide outstanding state blocks another operation ID while unresolved work exists. An older operation cannot mutate/reacquire after a newer operation is admitted on that domain. These are logical tests, not a distributed lock, concurrent-process linearizability or database fencing proof.

Intent immediately preserves possible-effect uncertainty even when no dispatch observation exists. Effect and observation availability stay separate. Known app success survives an unknown CMS outcome; no rollback/compensation is inferred. New attempts require reviewed synthetic no-effect evidence; completed success cannot be silently replayed or rewritten. Lost modeled authority blocks new records/takeover until explicit modeled quiescence, a new epoch and fresh matching inventory/review. New epochs cannot cancel real work; there is no effect dispatcher. Conflicting/foreign/ambiguous/unavailable inventory quarantines, and a later observation alone does not clear a prior unresolved finding.

## Trust limits, preservation and next proposal

Reconstruction feeds acknowledged canonical events into a **new memory model instance** under a supplied simulated checkpoint. It is not a new OS process, disk persistence, durable acknowledgement, independent custodian or hosted restart. Missing/reordered/truncated history and a mismatching supplied head refuse. A deliberate control shows that a replacement history **with its own matching checkpoint is accepted** while `authenticated=false`: hashes do not supply authenticity or currentness. Existing real recovery/custody and reader-process interruption proofs retain their separate historical evidence; this model does not inherit their authority.
