## Synthetic evaluation tooling

`evaluateSyntheticBatch` is offline test tooling over the installed grounded-analysis and photo-reading validators. `node scripts/verify/phase2-evaluation-local.mjs` prints a fixed eight-case synthetic rehearsal without reading external files, images, credentials or making provider calls. Four explanation examples cover supported selection, injected prose, an unsupported numeric field and refusal. Four photo examples cover a clear field, blur/abstention, partial DOT and an unsupported condition claim. These eight fixed responses are not50 explanation evaluations or50 representative images.

The input contract accepts only synthetic batches, a valid explicit clock, a closed case/cohort/split shape, unique case/input digests and bounded payloads. A synthetic group cannot cross development/held-out splits. These supplied synthetic identities are bookkeeping, not authenticated provenance, near-duplicate detection or evidence that a real benchmark is independent. Actual dataset admission remains separate future work.

An explicit null output remains unmeasured rather than becoming a successful rejection. Undefined outputs and non-string enum wrappers are refused as invalid input rather than being counted as measurements. Every supplied case contributes to the completion accounting. The report contains aggregate expected-outcome mismatches, per-field labeled/emitted/correct/incorrect/abstained/missed counts and cohort counts. Precision uses correct usable emitted values divided by all usable emitted values; abstention uses abstained fields divided by all measured labeled fields. A measured photo refusal or rejected schema supplies no usable field values and counts as abstention for every field, including missed expected values. Only an explicit null output is excluded as unmeasured. Empty denominators stay null. The95% Wilson interval describes finite synthetic-count accounting only; it does not establish independent representative sampling or real model accuracy. A wrong reading or missed expected value fails the local expectations. Rejected schemas and refusals are also reported separately from accepted readings.

Raw model text, prompts, photo text, labels, case/group/source identities and private inputs do not leave the aggregate report. No automatic usefulness score or critical-model-safety claim is fabricated. Actual model evaluation is always false, actual representative-image and specialist-label counts are zero, critical model misclaims are null, and accepted/case/gate outputs remain false/zero even if all local expectations match. Thresholds and benchmarks require external decisions; this tool cannot grant authority or promotion.
