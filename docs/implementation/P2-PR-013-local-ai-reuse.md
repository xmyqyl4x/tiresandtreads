## Exact private and reviewed public reuse

The report service retains the original immutable packet and exact canonical manifest. Scope, captured permission/invalidation revisions, policy configuration, provider/model/prompt/schema/validator/canonical versions, source/bundle/engine/rule identities and authoritative report hash participate in the existing digest. Serialized private command receipts bind each command key to its owner scope, digest, report/version and request. Concurrent exact misses coalesce; new command keys may use a current accepted artifact only within that same owner/report/version. Changed-body key replay conflicts. Foreign owners, revoked scopes, changed sources and expired results cannot reuse it. No owner result is promoted to public scope.

A separate generic service accepts only policy-allowlisted coarse enum parameters (currently US/en-US), rejects all private/free-form/unknown fields, and uses an explicitly reviewed context-independent advice fact with pinned text, source rights/expiry and renderer version. Reviewed definitions are immutable, newest topic/template review supersedes older versions, and retiring the newest does not resurrect an older one. No user identifiers, reports, image hashes, arbitrary text or location enter its shared manifest or demand counters. Output is a constrained selection of the reviewed fact and fixed question codes; the renderer copies the reviewed text and citations. Actual specialist quality acceptance remains pending.

Every enqueue, dispatch, publication and read rechecks current policy, scope and source. Shared soft refresh leaves the still-valid old artifact readable while a fenced lease builds its replacement. The trusted hourly operation selects only keys with at least three hits in the preceding 24 hours, at 80% of validity, and schedules no more than 25 keys per UTC hour globally across concurrent invocations. It never refreshes owner reports/images. Maintenance expires at most 25 cold shared rows, deletes bounded old operational counters, and requires no raw private lease-update permission. A validity cap can shorten the normal seven-day/source-bound ceiling; it cannot extend it. An exact cold miss after a terminal or expired result starts a fresh generation, while the serialized pending lookup coalesces concurrent callers. Bounded expiry commits in a separate transaction before refresh enqueue takes scope roots, so maintenance never carries a reuse-row lock into that opposite lock order.

## Cost admission and provider health

A reviewed immutable price plan is mandatory. No monetary defaults or real provider rates are supplied. Integer ceiling arithmetic reserves the configured input/output upper estimate (at least one minor unit) in policy/day, policy/hour and owner/day windows where applicable, before dispatch. Locks serialize concurrent limits; configured concurrency is bounded to one–four. Report/generic transports cap input at 65,536 tokens and output at 4,096/512 respectively; the plan must match those ceilings. These are conservative local contract limits, not measured real-model pricing or provider account acceptance. Operator/provider-account allocations remain unconfirmed.

The common application runner preserves the report service's transaction boundaries. Calls occur outside SQL; immutable measured charge settlement commits before runtime bookkeeping and publication. Unknown/timeout costs retain reservations. Exceeding a price/token ceiling blocks the plan and publication, preserves uncertainty and requires a new reviewed policy/plan. It cannot silently release or undercharge a known overrun. No exactly-once provider billing or independent external cancellation guarantee is claimed.

Only incomplete output with known reconciled cost may retry automatically: two retries at two/four seconds, three total attempts, within the original 120-second request and 30-second job lease. Refusal, malformed output, timeout, network uncertainty and interrupted dispatch do not trigger blind redispatch. Attempt identities, request roots, reuse holder/fence and circuit generation are checked by database guards. A per-policy circuit opens after three failures for 60 seconds, permits one 30-second half-open probe and rejects old-generation completions changing new circuit state. An expired owned synthetic dispatch is recovered as uncertain after service recomposition, including interruption after charge settlement: finalized attempts and recorded charges remain unchanged, and only still-started attempts gain an uncertain outcome; this test uses controlled timestamps and does not claim a real process-kill/provider cancellation experiment.
