Dedicated `ready` and `notifications` selections apply current request state, delay, lease, settling barrier and proof conditions before a bounded 1–100 result limit. Selection grants no authority: the worker still acquires/rechecks its generation fence. Access/export/correction and active holds remain human cases. A real PostgreSQL regression puts eligible work behind 101 manual cases and proves progress without disabling constraints.

The headless maintenance factory binds existing delivery, verified callback, CMS publication, privacy, analytics, limiter, source and retention services. Actions default disabled. A cycle accepts at most four distinct known actions, and each queue action invokes at most four candidates. Processed counts successful service invocations; it does not assert completed delivery or erasure. Local overlap returns busy. Failures are redacted, independent actions continue, and there is no automatic coordinator retry. It neither resets a job nor force-sends mail, waives deletion/consent or mutates scoring. Underlying SQL leases and permanent effect identities remain authoritative. Retention and object work default to dry-run; apply requires explicit host configuration and reviewed jurisdiction policy.

An optional local Inngest function binds the named cycle to a one-minute cron, concurrency one and no transport retries; it is absent without a supplied callback. Existing SQL job/outbox reconciliation remains separate. This declaration and an in-process overlap guard do not prove hosted distributed concurrency, signing, cancellation or universal exactly-once network effects. Actual host wiring, provider settings and global connection accounting remain explicit in the gate register, including overlap with S4/031.

`admin.service_health` provides ten identity-free series: executable privacy backlog, necessary verification, overdue rights, scheduled/uncertain mail, callbacks, analytics, outbox, unknown recovery commands and quota capacity. Non-quota samples stop at 1,001 rows; capped means a lower bound. Oldest timestamps come from ordered bounded samples; future availability has zero age. The quota counter is exact.
