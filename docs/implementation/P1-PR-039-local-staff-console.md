## Usable operator views and actions

The separate staff bundle provides masked report, send, callback, privacy and import queues; source health and published-bundle freshness; SEO findings and the strategic register; consented aggregate analytics; advertising revenue status; and current/reviewed configuration. Pagination replaces one bounded page instead of accumulating an unbounded browser list. Counts reaching the health sampling cap are labeled. Missing aggregates/reports are unavailable, not zero. Provider revenue stays in exact strings and currency minor units, with estimated/finalized status and nullable ratios; no FX, profit or all-visitor coverage is inferred.

Recovery requires a target reference, a SHA-256 evidence reference and explicit operator review. It delegates to the existing audited recovery service: no force-send, arbitrary job reset, consent override or ingestion bypass. A lost acknowledgement freezes the original command key/input. A later permission failure or CAS conflict cannot resolve that earlier uncertainty. Recorded `unknown`/`executing` outcomes remain unresolved. Same-staff session renewal verifies a fresh server grant/MFA and the original staff identity, preserving pending work; switching identity requires disconnecting. Configuration retries retain their original policy/key/version, while current reviewer authorization can be renewed. Inspecting current policy never proves which unknown command applied. Existing services remain authoritative.

Configuration requires a validated preview, optimistic version and a distinct currently permitted reviewer with recent MFA. Publication records the existing versioned audit; it activates no external advertising. Failed local JSON/field validation dispatches nothing. The loopback ingress forwards reviewer authorization only on the exact configuration publish path. The fixed web proxy strips cookies and arbitrary upstream/forwarded headers, bounds request/response streams and deadlines, and refuses other write surfaces.

Credentials stay in page memory and headers. The console stores no staff credential in browser storage, cookies, URLs or serialized HTML. Disconnect clears page credentials and explicitly leaves any unknown command subject to audit reconciliation. Public visitor JavaScript retains its existing 120,000-byte gzip budget; the independent private console has a 250,000-byte gzip ceiling. TypeScript diagnostics measured about 1.1 GiB, so the compiler-only allowance is now bounded at 1.5 GiB; runtime, connection, browser and test thresholds are unchanged.

Workspace type checking runs the web asset/type step before root consumers of its generated renderer declaration. This order supports fresh checkouts without depending on a previously populated build cache. Proxy handling is separate from SSR document generation, so unit tests run without generated renderer assets; the actual Next/PostgreSQL test verifies the rendered staff shell.
