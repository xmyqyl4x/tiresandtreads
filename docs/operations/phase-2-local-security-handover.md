This runbook covers the disposable P2-PR-026 rehearsal. It does not appoint an operator, approve provider/model/source rights, supply real identity/MFA, authorize recipient notifications or accept hosted operation. Primary/backup operators, coverage, rates, budgets and external escalation contacts remain unconfirmed.

## Reproduce the local evidence

Run `node tests/fixtures/phase2/security-gate-run.mjs` for strict Linux compilation and the combined security/privacy proof plus relevant existing regressions. Run `node tests/fixtures/phase2/security-preview.mjs` for the separate interactive disposable preview. Both create only an ownership-tracked random `tt-test-*` environment and remove its resources. Neither accepts arbitrary database URLs, archive paths, SQL commands or hosted targets. Retained dev/stage resources are not reset.

The interactive preview exposes synthetic role handles in its local readiness record. These are fixture identities, not credentials for production. Its original owner report remains available for explicit browser processing. A separate synthetic report exercises the real branded renderer and writes a PDF/HTML proof inside the owned tooling container. Mail goes only to an in-memory test sink. Do not copy those handles or renderer links into production configuration.

The preview's fixed fixture issuer accepts at most eight explicit `SIGUSR2` renewal signals to the identity-checked `serve-security.ts` process in its owned tooling container. Each signal issues new short-lived handles for the same seven synthetic staff identities and emits `LOCAL_P2_SECURITY_REAUTH`; it does not renew old handles, change roles, extend the production MFA window or expose an HTTP renewal endpoint. Reconnect through the UI and reconcile the original receipt before any replacement operation. This helper is not a real identity-provider or MFA acceptance proof.

On a failed run, retain the masked console evidence and identify the first failed boundary before retrying. Let the owning controller perform teardown; do not run a global Docker prune, terminate an unidentified database backend or delete an unrelated environment. The preview ownership record is `.local/p2-security-preview.json`; its project must match the controlled process before stopping it. A new run must refuse pre-existing restore targets or archive files rather than replace them.
